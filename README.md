# reference_color_composition_morehub

Simple D3-based color composition viewer for the MoreHub model palette.

## Run

1. Open `index.html` directly in your browser, or serve this folder with any static server.
2. Use the checkbox on each row to include/exclude that color from bulk exports.
3. Click `Copy` on a row to copy `MODEL_NAME: #HEX`.
4. Click a hex value to copy only the color code.
5. Use the bottom `JSON Style` and `Python Style` copy buttons to copy all currently selected colors at once.
